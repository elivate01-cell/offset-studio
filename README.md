# OFFSET/STUDIO

An editorial portfolio template for a fictional independent multidisciplinary studio. All project names and narratives are fictional; the photography is used as visual reference material and does not imply a client relationship.

## Run

```sh
npm install
npm run dev
```

Hash routes include home, work index, four project details, studio and contact. The site is frontend-only.

## Photography

## Typography

Newsreader and DM Mono are served through Google Fonts and released under open font licenses. System fallbacks remain usable if font delivery is unavailable.
